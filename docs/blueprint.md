# **App Name**: Caseflow CRM

## Core Features:

- Role-Based Login: Login and role-based access control for admins and staff.
- Dashboard Overview: Dashboard to display key stats for admins and assigned tasks/cases for staff.
- Cases Management: Cases Management: Table to filter, sort and manage customer support requests. Add case button which can pre-fill info from incoming email
- Tasks: Task management: to-do list with drag-and-drop prioritization. Staff can set task statuses.
- Contacts/Accounts: Directory of customer contact information
- Admin Panel: Admin panel to add/edit roles and create teams. Limited to managing app users (no access control to database).

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and stability.
- Background color: Light gray (#F0F2F5) to ensure a clean, professional interface.
- Accent color: Vibrant orange (#FF9800) for interactive elements and call-to-action buttons.
- Font pairing: 'Inter' (sans-serif) for body and 'Space Grotesk' (sans-serif) for headers, lending a clean and modern appearance.
- Consistent use of material design icons to provide recognizable and intuitive visual cues.
- Responsive layout adapting to different screen sizes using a mobile-first approach, utilizing collapsible sidebars and stacked cards for smaller screens.
- Use subtle transitions and animations to provide feedback and improve the user experience, such as sliding sidebar drawers or smooth state changes.
